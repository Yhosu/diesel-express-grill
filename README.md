# Diesel Express Grill — Sistema de Control Operativo, Costos BOM y Conciliación Móvil

Sistema construido con **Laravel 12 + Filament v4** para el control integral de las unidades móviles de **Diesel Express Grill** (Despacho Diario, Ventas POS Efectivo/QR, Control de Mermas `W01..S01`, Recetas BOM de 10 Productos, Compras de 29 Insumos, Egresos Operativos y Reportes Ejecutivos por Fecha).

> **Documentación Completa de Contexto:** Lee el archivo [`CONTEXTO_PROYECTO.md`](./CONTEXTO_PROYECTO.md) en la raíz de este proyecto para conocer el detalle paso a paso de la arquitectura, fórmulas matemáticas, estructura de base de datos, servicios de dominio y convenciones de Filament v4.
